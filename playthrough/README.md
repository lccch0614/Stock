# 60 日期權限定挑戰 · 真實遊戲引擎試玩

## 結果

初始資金 $10,000；第 60 日所有期權已平倉或現金結算，現金及淨值均為 **$15,479（+54.79%）**。距離 $20,000 仍欠 $4,521，**挑戰未達標**。每日記錄中最高淨值 $16,541；沒有以盤中浮盈宣稱達標。

共 39 次完整價差開倉，16 次提早整組平倉、23 次到期結算。以完整開倉組別計，32 組盈利、7 組虧損。期權費共 $590，另有實際 Bid／Ask 價差影響，全部已反映結算。每日記錄最大回撤約 26.75%，不是盤中最大風險。沒有正股交易、股票沽空、注資或現金任務獎勵。

各 ticker 淨損益（包含相應開平倉費）：BIOV +$1,133、QBIT −$2,086、SOLR +$3,823、NVXT +$2,609，合計 +$5,479。勝出組數多並不足以保證達到資金目標；少數虧損及持倉規模仍明顯影響結果。

收市／當日操作後淨值里程碑：D10 $11,354；D20 $9,768；D30 $9,973；D40 $13,152；D50 $14,899；D60 $15,479。journal 的 D0 是初次開倉後 $9,802，因開倉費及 Bid／Ask 即時估值而低於本金；initial-save.json 才是交易前的 $10,000。

## 試玩方法

這是程式化試玩：透過正式遊戲的 strategyPreview、strategyOpen、strategyClose、advanceDay 執行，而不是人手於瀏覽器逐次點擊 60 日。瀏覽器介面檢查另外記錄於 TEST_RESULTS.md。

固定原本預設 seed 20271025。單一路徑向前推進，不挑選市場種子、不讀取未來價格、不更改本金、RNG 或成交規則。政策函式獨立放於 policy-public.cjs，只收到當日公開報價、當前持倉及首日公開價格；沒有 engine、RNG、隱藏錨點或未來事件存取權。

規則在執行前寫定：選公開波動設定較高的 BIOV、QBIT、SOLR、NVXT；現價不高於首日公開價格時採 Bull Put，較高時採 Bear Call。短腿選目前價外／平價附近 5 元格點，保護腿相隔 5 元，同到期 7 個交易日。每股票建倉最大風險最多約當時淨值 20%，並於開倉檢查保留 20% 可用緩衝。捕獲約 80% 開倉淨權利金則平倉；估計平倉虧損達初始最大風險 80% 則止損；否則可持有至到期。這些是每日檢查，跳空仍可超過提醒值。最後不足 7 日不新開倉，第 60 日強制結束挑戰所有持倉。若可平倉淨值曾達 $20,000，原規則會清倉結束；本次沒有發生。

規則實際只選用 Bull Put 及 Bear Call 兩種信用價差；遊戲其餘兩種垂直價差仍由回歸測試驗證。這不是最佳策略搜尋，也不是投資獲利保證。

## 技術中止與重播

首次程序在舊計劃仍佔用同一股票時中止，未產生成績；result-aborted-plan-handoff/ 保留開始 manifest、初始存檔及說明。修正計劃生命週期後，沿用同一初始種子及政策重播完整路徑，得到 $15,479。後續把平倉狀態即時同步到介面，再以最終引擎重播審核；所有 actions、成交、ledger、daily-equity.csv 完全相同。attempts/ 保留第一次完整執行的摘要及來源雜湊。沒有另換策略或只保留較佳行情。

result/ 為最終引擎的可審核紀錄。manifest-before-run.json 在推進行情前寫出，包含政策、執行器及引擎 SHA256；summary.json 包含結算、費用及存檔雜湊。final-save.json 是可匯入遊戲的挑戰存檔，匯入前請先備份自己的生涯。

最後平倉發生在 D60 凍結收市簡報之後，因此簡報可能仍顯示平倉前估值；當前帳戶、ledger 及 final-save 均已平倉並扣費，差異屬收市後手動交易，不改寫舊簡報。計劃卡的最終狀態是「待收市復盤」，不為補報而推進到 D61。

如要獨立重播，在解壓根目錄執行：

```
PLAYTHROUGH_OUTPUT=./work/my-replay node playthrough/run.cjs
```

選不存在的新目錄；程序拒絕覆寫既有紀錄，避免不小心以另一輪替換結果。測試套件的審核重播亦比較每筆交易及每日淨值，並不把再次驗證算作新挑戰。
