# Stock Market Tycoon V2.5.0

繁體中文股票投資生涯遊戲；15 間虛構公司、模擬市場與虛擬資金。純靜態多檔案網站，可直接放上 GitHub Pages；遊戲執行不需要安裝依賴、API 金鑰或外部服務。

## 本版新增

- 六項生涯任務，涵蓋資金管理、限價執行及有界風險價差。最多同時接兩項；完成前置任務後解鎖進階挑戰。只獎勵 XP／稱號，不派現金。
- 可選交易計劃卡：工具、股票、預算、理由、最多持有日數及止盈／止蝕提醒。相符開倉會連結；預算超額會留痕，不禁止原有交易。
- 秘書明日行動頁加入任務進度、剩餘日數、預算合規、退出提醒及交易復盤；執行紀律與金錢損益分開評估。舊簡報維持原樣。
- Lv.4 Professional Trader：從 Lv.3 起須同時達到淨值 $100,000、60 個交易日、三類任務各至少一項、最近 20 個收市最大回撤不超 20%，以及沒有現金抵押缺口。晉級後不降級。Lv.5–7 仍屬後續規劃。
- 風險分數按整組策略計算；Covered Call 與鎖定股票合併避免重計。提供所有股價同時 ±10% 的模型情境。
- Schema 5 保存任務、計劃及復盤；支援 schema 1–4 遷移。原來的現金、持倉、交易、RNG、新聞、簡報及秘書待辦保留，不補作歷史任務或 XP。

## 開始使用／GitHub Pages

1. 先在舊網站「設定」匯出 JSON 備份。
2. 解壓，將 **Stock-Market-Tycoon-V2.5.0 目錄內的內容** 放入原 GitHub Pages 發佈目錄。保留 index.html、js/、styles/ 及 .nojekyll；所有資源用相對路徑，支援 repository 子路徑。
3. 保留原網址與瀏覽器，重新整理；瀏覽器本機存檔會自動遷移。不同網域／裝置須自行匯入備份。
4. 本地可執行 `python3 -m http.server 8080`，再開啟 localhost。遊戲正式執行不需要 npm。不要以 file:// 測試保存行為。

沒有在本次工作中發佈或修改 GitHub 倉庫。

## 一次完整玩法

在「生涯進度」接取任務 → 在「交易計劃」選工具及股票，設定預算與退出提醒 → 手動確認交易 → 下一交易日閱讀簡報 → 檢視任務／預算／風險 → 決定持有或手動整組平倉。手機可從主頁「交易計劃」及「生涯任務」進入，也可在正股／衍生工具頁展開計劃卡。

計劃只連結建立後的相符開倉。正股／沽空已有同工具持倉時，先平倉才可建立新計劃，避免混淆成本歸屬。限價買單保存原計劃連結，即使之後選用另一張卡，成交仍記入原計劃。同一股票及工具最多一張待開倉／持有中計劃；平倉後可即日再建新卡，舊卡在下一個收市完成復盤。最多 12 張未結束計劃、100 張計劃記錄；超出時先輪替最早已結束記錄。

預算基準：正股為累計買入成本連費用；股票沽空為初始 50% 額外保證金連費用；期權為所需新增資金（信用價差為寬度減淨收權利金）。期權每卡連結一個 group；部分平倉合併已實現與餘下估計平倉損益。比例提醒使用原累計投入，並不按每次減倉重新縮小分母。已觸發提醒會保留，沒有盤中自動止蝕或自動交易。

任務從下一個收市起計算，限期當天仍可完成；下一天才逾期。失敗／放棄可重接，已完成任務不能重複領 XP。限價／價差任務只認接任後新建計劃；不會把舊成交當新任務。執行任務要求預算合規，策略任務另要求最大建倉風險不超當時淨值 15%（進階為 8%），完成整組平倉或到期結算並復盤；不要求一定盈利。

## 風險計算範圍

每個 ticker 合計剩餘風險，再以最大單一 ticker 比例及歷史回撤計分。長期權／垂直價差：目前 Bid／Ask 有號平倉估值減最差到期給付；Covered Call 合併對應股票；CSP 計入最差向下給付。這個數值是目前持倉的剩餘風險估計，與建倉最大損失不同。股票沽空／Covered Put 仍有上漲無上限風險，分數以沽空名義負債代用，不能視作真正最大損失。

±10% 情境以目前各腿 IV、剩餘時間及理論價格差計算，同時改變所有股價，不改變時間或 IV；不計新增費用、滑點與成交限制，不是預測或壓力測試的完整集合。抵押計算仍沿用原有規則，沒有因分數改動而減少必要抵押。

## 保留的交易及帳務規則

- 正股市價／限價／止蝕、歷史圖、新聞、交易成本、資產曲線及原 Lv.1–3 條件。
- 股票沽空：所得鎖定，另預留現值 50%，30% 維持比例，年化 3% 借股費／252；不足時原有強制回補保留。
- 歐式現金結算期權，每張 100 股；多倉 Ask 開／Bid 平，空倉 Bid 開／Ask 平，每腿每張開平各 $1，到期無額外費用。無提前行使。
- Long Call／Put、Covered Call、Cash-secured Put、Covered Put，以及 Bull Call／Bear Put／Bull Put／Bear Call 四種完整垂直價差。禁止裸賣與拆腿，原子整組開平倉及部分整組平倉保留。
- 信用價差鎖完整寬度，權利金留在現金；CSP 鎖 K×100，結算後不獲股票；Covered Put 同時鎖沽空股及全額 K 現金，屬保守遊戲簡化。Covered Call 到期價內時出售鎖定股支付現金結算。
- 抵押不重複扣除淨值；可用現金扣除掛單、沽空所得、保證金及期權抵押。持倉面板跨頁顯示當日模擬現價、整組 P&L 及 Greeks。
- 五頁收市簡報、最多三項規則型建議、下一回合待辦、90 份凍結歷史簡報、逐日閱讀及連續播放。
- 可略過／重玩八步互動教學，獨立練習帳戶；有確認及可選匯出備份的重新開始；儲存失敗回滾、防止損壞存檔自動覆寫。

Lv.2 原本仍要求正股交易及限價單條件；期權資金挑戰的 $20,000 是金額目標，不能視作已達所有 Lv.2 條件。V2.4 的歷史模型說明見 docs/V2.4.0-Model-and-Legacy-Notes.md。

## 存檔與驗證

沿用 IndexedDB `stock-tycoon-mvp-v1`／saves／main，以及 localStorage `stock-tycoon-mvp-state`。教學不覆蓋生涯。遷移時新任務由升級當日起算，保留已有凍結簡報；新簡報才包含新風險與計劃欄位。JSON 匯入上限 20MB。

`npm test` 執行核心與試玩審核；DOM 檢查先 `npm install`（只有開發依賴 jsdom 26.1.0），再 `npm run test:ui`。一次記錄全部結果：`node tests/run-all.cjs --ui --report`。TEST_RESULTS.md 與 TEST_REPORT.json 記錄本次真實結果，productionSHA256 對應本套件前端檔案。
