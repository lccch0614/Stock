# Stock Market Tycoon V2.4.0 — 持倉監察與投資秘書

以本次交付的 V2.3.0 完整 ZIP 為基礎更新。原 ZIP SHA-256：`47832ae8c05baad4209323812d5572610cf6987621a5995668dd64751584a11b`。

本版保留正股、股票沽空、長倉及保護型賣出期權、四種垂直價差、整組開平倉、抵押會計、Lv.1–3 生涯、8 步新手教學、自動保存、JSON 備份與重新開始，新增跨頁持倉監察及每日收市簡報。

## 快速使用

1. 在右下角按「持倉現價」，任何頁面均可查看當前模擬報價、損益及可用資金。點選持倉前往交易或整組持倉頁。
2. 「投資組合」直接並列股票現價、平均成本、市值／負債、股價日變動、損益及百分比。期權保留 Bid／Ask、到期日、整組 P&L 和 Greeks。
3. 完成下一交易日後，預設暫停播放並顯示五頁簡報：「收市摘要」、「持倉表現」、「交易與成本」、「風險與資金」、「明日行動」。
4. 在「投資秘書」切換「逐日閱讀」或「連續播放」。連續模式每天保存簡報，保留目前頁面並累積未讀；可逐份閱讀，或按「全部已讀」。
5. 在最新簡報的「明日行動」加入下一交易日待辦，可前往檢查、標記已處理、略過及重新開啟。下一份簡報會回顧進度及條件變化。

所有價格隨模擬交易日更新，不是真實股票即時行情。顧問使用本機規則引擎，無需 API 金鑰或網絡連線。

## 每日簡報如何計算

每個回合依次完成行情更新、掛單成交、衍生品及借股費結算、維持保證金處理、歷史淨值及晉級檢查，才保存簡報。同一模擬日只保存一次。

日報區間是「上次收市／升級基準至今」。包括上次簡報後的手動買賣，即使交易日期欄仍顯示前一模擬日，也會按記錄先後納入新一份簡報。

- 回合損益 = 本次收市淨值 − 上次基準淨值。
- 正股、沽空及期權分別以期末有號市值變化，加上該類交易現金流計算貢獻。
- 三類貢獻顯示費用前數字，執行費及借股費另列一次，避免重複扣費。
- 期權沿用多倉 Bid、空倉 Ask、整組有號估值與 100 股乘數。
- 如存在其他現金變動或四捨五入差額，另外顯示調整項，保持與淨值變化對帳。
- 現金變化與損益分開顯示；抵押仍屬資產，不能再次從淨值扣除。

簡報保存當日行情、持倉、交易、費用、風險、建議及待辦回顧。後續行情及交易不會改寫舊簡報的財務數據。側邊的「現在的資金狀況」則清楚標示為目前模擬日資料。

每份簡報最多列出該回合最後 100 筆交易，合計數字包含該回合全部交易。存檔保留最近 **90 個交易日的完整簡報**，更早簡報會輪替並顯示數量；建議定期匯出 JSON 備份。

## 規則型顧問及待辦

每份簡報最多三項建議，按優先次序處理：

- 淨值非正、抵押缺口或沽空維持比例接近 30% 時的資金檢查。
- 距離到期不多於三個交易日的整組期權檢查。
- 單一正股／沽空名義持倉超過淨值 40% 的集中提醒。
- 可用資金低於淨值 10% 或 $100 的緩衝提醒。
- 歷史最大回撤達 15% 的持倉預算檢查。
- 生涯未完成條件及公開行情／新聞觀察。

40%、10% 與 15% 是本遊戲的規劃提醒門檻，不是券商規則。原有 Risk Management Score 仍保留，並非價差最大損失指標。

每項建議均有發現、原因、下一回合條件及檢查入口。分析只接收當日公開行情、新聞、持倉及帳戶快照，不接觸 RNG 種子、未來價格或隱藏事件。它提供條件式計劃與風險提醒，沒有預測勝率或保證回報。

加入待辦或點選「前往檢查」只會建立清單或開啟相關頁面。實際交易使用當時最新報價，再由玩家確認；原有費用、抵押和整組成交規則仍然適用。

待辦回顧會區分玩家標記、已平倉或到期、資金緩衝恢復、集中度改善及生涯晉級。價格變動本身不會被描述為已執行某筆交易。最多保留 100 項待辦；達上限時先輪替已回顧完成／略過項目。

## 存檔與升級

沿用 IndexedDB `stock-tycoon-mvp-v1` → `saves` → `main` 及 localStorage `stock-tycoon-mvp-state`。V1、V2／V2.2、V2.3.0 schema 3 會遷移至 **schema 4 / gameVersion 2.4.0**。

升級時保留現金、持倉、價格、市場 RNG、掛單、交易歷史及生涯。以升級當下的帳戶建立日報起點，從下一交易日產生第一份簡報，不補作缺少日終資料的歷史簡報。新存檔包含簡報、閱讀模式、已讀狀態、待辦及計算基準。匯入支援最大 20 MB JSON。

新手教學繼續使用獨立練習帳戶；練習的簡報和待辦不寫入生涯。重新開始會清除簡報、待辦及日報基準；原有確認及可選 JSON 備份保留。讀取損壞資料時停止自動覆寫，保留原始備份入口。

升級前先匯出原版 JSON。新版存檔不能保證由舊版載入。

## 交易模型

沿用 V2.3.0 的模擬模型：一張期權對應 100 股，每腿每張開平倉各 $1；歐式現金結算，沒有提前行使。Covered Call 鎖定正股，到期價內時按現價出售對應股票以支付短 Call 現金結算；Cash-secured Put 預留全行使價現金，到期不新增股票；Covered Put 需沽空股份並採保守現金雙重抵押。信用價差預留整個寬度，權利金留在現金內。

原版平均成本以美分保存，持倉未實現損益可能有少量四捨五入差額；每日簡報則以現金及有號市值變化對帳。

股票沽空保留 50% 初始額外保證金、30% 維持比例及年化 3% 借股費。跳空仍可能造成負資產。相關完整模型及原版限制見 `docs/V2.3.0-Model-and-Legacy-Notes.md`。

## GitHub Pages 與本機執行

網站無需建置，遊戲運行沒有套件、CDN 或伺服器依賴。

1. 解壓 ZIP，將專案資料夾**內的內容**上傳原 repository 的網站根目錄。
2. 保留根目錄的 `index.html`、`.nojekyll`、`js/` 及 `styles/`。
3. 沿用原 GitHub Pages 分支設定；新設定可選 Deploy from a branch → 分支 → `/ (root)`。
4. 使用原網站來源網域保留瀏覽器存檔。更換瀏覽器或網域時，以 JSON 備份搬移。

腳本及樣式使用相對路徑，支援 repository 子路徑，並以內容雜湊查詢參數識別新版資源。若更新後仍見舊畫面，可重新整理頁面。

本機在專案目錄執行 `python3 -m http.server 8080`，再開啟 `http://localhost:8080/`。測試用手機寬度預覽可開啟 `/tests/responsive-preview.html`。

本次交付是完整本機 ZIP，沒有代為上傳或部署 GitHub Pages。
